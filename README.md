Getting started with MyCustom

1. Install

Install BetterDiscord from betterdiscord.app.
Download MyCustom.plugin.js.
In Discord, go to User Settings → BetterDiscord → Plugins → Open Plugins Folder, and drop the file in.
Switch MyCustom on.

2. Send your first message
Type (wave/hello everyone) and press Enter.
The plugin turns it into an animated image and puts it in your upload tray.
Press Enter again to send it.
Messages without effects are sent normally, as plain text.

3. The basics
Effect: (wave/text), (rb/text), (shake/text), (glow/text)
Color: (#ff0000/text)
Gradient: (#ff0000>#0000ff/text)
Stack them, with the text always last: (#ff0000/wave/glow/text)
Whole message: put /nudge, /shake or /billboard anywhere in it
No codes: select text, right-click the message box → MyCustom

4. Make it yours
In plugin settings ⚙️:
My emojis: add a picture, then type .name. anywhere
My fonts: add a font, then use (fonta/text) (it goes from fonta to fontb and then if you run out of spaces it goes to fontaa, fontab....)
